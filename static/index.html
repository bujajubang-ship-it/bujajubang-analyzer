🛍️ 쇼핑 키워드 분석기 네이버 쇼핑
  • 내 취향으로 고르지 마라. 데이터·숫자로만 골라라. (내 눈에 예쁜 건 그냥 내 장바구니)
  • 잘 팔릴지는 소비자가 판단한다. 여러 개 올려보고 팔리는 걸 키운다.
  • 검증 먼저, 사입은 나중. 위탁/소량 테스트로 팔리는 걸 확인한 뒤 돈을 넣는다.
  • 판매량 = 노출수 × 클릭률 × 전환율 (셋 중 하나라도 0이면 0)
    • 노출수 = 시장·경쟁이 결정(통제 불가) → "들어갈 시장" 고르는 게 전부
    • 클릭률·전환율 = 내 실력으로 올린다(썸네일·상세·쿠폰·리뷰)
  • 데이터 해석력이 경쟁력. 비즈니스 인사이트는 모두에게 공개된 데이터 — 먼저 익히는 사람이 이긴다.
  • 아이템스카우트 → 3차 카테고리까지 파고들어 키워드 하나씩 훑기
  • 경쟁강도 지표는 무시(프로그램 등록으로 왜곡됨) → 검색수 + 실제 셀러 수준을 봐라
  • 셀러라이프 키워드 검색으로 네이버·쿠팡 연관 키워드 함께 수집
  • 1페이지 직접 확인 (쿠팡에 키워드 입력)
    • 1~10위 전부 로켓 → 포기 (못 뚫음)
    • 일반 판매자(윙) 3명 이상 → 진입 가능
  • 순위 변동 그래프
    • 상위권 고정 → 벽 단단함, 포기
    • 순위가 왔다갔다 → 후발주자에게 기회
  • 비즈니스 인사이트 → 카테고리 분석
    • 광고 비중 70% 시장 피하고 20% 이하 노려라
    • 노출 큰데 광고 비중 낮은 카테고리 = 보물
    • 고객/검색 증가율 > 상품 증가율 = 수요 > 공급, 돈 버는 시장
  • 탑20 검색어 × 평균가로 예상매출 계산 (전환율 보수적 3% 기준)
  • 판매가는 시장이 정한다. 시장가에 맞출 수 있는 원가의 제품을 찾는다(못 맞추면 포기)
  • 순서: 도매꾹 단가 확인 → 1688에서 같은 제품 비교
  • 원가 환산: 한국 원가 = 위안화 × 350원 (환율+수수료+세금+통관 어림값)
  • 도매꾹 vs 1688
    • 처음엔 도매꾹 위탁으로 테스트(재고 리스크 0)
    • 꾸준히 팔리면 1688 사입 전환(가격 컨트롤, 마진↑)
    • 도매꾹 한 곳만 믿지 마라 → 1688 루트 미리 확보
  • 1688 좋은 판매자: 일반 < 황소 < 보라색 슈퍼팩토리(공장실사). 카테고리 전문 판매자를 골라라
  • 1688 알리왕왕으로 판매자에게 직접 가격 협의(파파고 한국어→복붙)
  • 여러 판매자에게 동시에 같은 질문 → 응답 빠르고 이력 좋은 곳 선택
  • 처음엔 10% 깎고, "100개 단위면 얼마?" 대량 단가도 미리 확인(마진 시뮬레이션)
  • 배대지 선택 4기준: 소통 / 환율 / 운임 / 숨은 추가요금 — 2~3곳 운영(리스크 분산)
  • 공장 가까운 배대지로 보내면 더 빠르고 싸다
  • 수입 방식: 20kg 미만 특송 / 20kg 이상 LCL / 대량 FCL(통관 가장 빠름)
  • 기본 검수 신청 필수 → 도착 사진 확인 후 출고 요청
  • 매입 증빙 보관: 수입신고필증 + 배대지 세금계산서 (부가세·종소세에 필수)
  • 의류는 초보 비추(컬러·사이즈 재고관리 어려움). 사이즈 비율은 1등 리뷰 분석
  • 테스트 단계: 도매꾹 + 1688 이미지 섞어서 올리기(그대로 쓰면 아이템위너로 묶임)
  • 대표 이미지 = 시선 끄는 자극적인 컷. 추가 이미지 9개 다 채우기
  • 사입·정식 단계: 차별화 포인트(우리 제품만의 장점)를 스토리로 녹이기
  • 상품명 맨 앞에 브랜드명(아이템위너 방어 + 상표권 소명)
  • 노출 = 상품명 + 검색어 태그 조합. 쿠팡은 정확히 일치 안 해도 "살 것 같은 사람"에게 자동 노출
  • 연관 키워드를 검색어에 최대 20개 채우기(아이템스카우트·셀러라이프)
  • 옵션명도 살짝 변형(번들 키워드 포함) → 아이템위너 매칭 회피
  • 카테고리: 1등 판매자가 쓰는 카테고리 따라가기(쿠팡 개편 잦음, 유연하게)
  • 무료배송 필수 — 배송비를 판매가에 녹여라(상위 노출 가산점)
  • 출고소요일 짧게 — 초기엔 당일출고(상위 노출 점수)
  • 재고수량 9개 — '품절 임박'으로 조바심 유발
  • 즉시 할인쿠폰 — 정상가 높이고 할인 적용(빨간 딱지, 전환율↑) [프로모션 → 할인쿠폰 관리]
  • 자동 가격 조정 ON — 아이템위너 방어용 최저가 미리 설정
📣 광고 운영
  • 매출최적화 광고 + 자동 운영으로 시작(초보는 AI 스마트 광고 켜고 등록에 집중)
  • 캠페인 이름 = 날짜 + 윙/로켓 + 상품명 + 최소ROAS%
  • 최소 ROAS = (판매가 ÷ 마진) × 1.1. 이 아래면 광고할수록 손해
  • 목표 ROAS 낮게 = 넓게 노출 / 높게 = 좁게. 쿠팡 기본 추천 350%
  • 세팅·변경 후 최소 1주일은 건드리지 마라(AI 학습 시간)
  • 광고비 소진 알림 메일 설정 — 피크타임(점심직후·퇴근후·취침전)에 살아있어야
  • ROAS 높다고 많이 버는 거 아님 — 500%×50개 > 1000%×10개
♟️ 시장 역학 (고수의 영역)
  • 광고는 혼자 하는 게임 아님. 안 바꿨는데 수익률 변동 = 경쟁자가 조정한 것
  • 수익률 갑자기↑ = 경쟁자 공격 진입 가능 → 줄이지 말고 더 투자해 싹을 잘라라
  • 광고비 잘 소진 + 판매↑ = 누가 빠진 것 → 역시 더 투자
  • 광고를 올렸다 내렸다 흔들어 경쟁자 반응 유도(비즈니스 인사이트 시간별 랭킹으로 확인)
📈 전환율 관리
  • 10위권 진입 + 리뷰 확보인데 전환율 10% 미만 = 안 되는 상품. 시장 평균과 비교 필수
🛡️ 아이템위너 방어
  • 묶이면: ① 문의에 상품ID·판매자코드 첨부해 분리요청, 또는 ② 상품정보에서 브랜드·제조사 변경(즉시 풀림). 해제 후 원인(겹친 이미지) 반드시 변경
  • 처음부터 상표권 등록 브랜드명을 상품명 앞에 = 최선의 방어
🚀 로켓그로스 전환
  • 검증 끝난 상품 → 로켓그로스(쿠팡 배송·CS 전담 + 로켓배지로 판매↑). 품목당 10개 소량 입고, 60일 무료보관. 바코드·동봉문서·박스문서 빠짐없이
