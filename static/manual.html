📒 이카운트 입력 매뉴얼

자금 대시보드에서 부서별·직원별·프로젝트별 매출/비용/순이익이 자동으로 정확히 계산되도록 하기 위한 입력 가이드입니다.

한 줄 요약: 입출금마다 ① 프로젝트명 꼭 적기(영업은 끝에 담당자 이름) · ② 쇼핑몰은 '쇼핑몰' 글자 · ③ 투자·정부지원 출금은 적요에 키워드. 계정과목은 평소대로.

✅ 매일 입력 3원칙

  1. 모든 입금·출금 전표에 "프로젝트명"을 반드시 입력 (비워두면 분류가 안 됩니다)
  2. 담당자가 있는 영업 건은 프로젝트명 끝에 담당자 이름을 붙입니다
  3. 특수 항목(투자·정부지원)은 적요에 지정 키워드를 적습니다

1. 프로젝트명 입력 규칙 (제일 중요)

① 쇼핑몰 매출·비용

네이버·쿠팡·카페24 등 온라인 판매 관련은 프로젝트명에 "쇼핑몰" 글자가 들어가게 합니다.

예) 쇼핑몰 · 쇼핑몰 / MD · 쇼핑몰 광고비

② 영업(B2B) — 담당자별

형식: 거래처/현장명 - 담당자이름. 담당자 이름은 아래 중 하나로 정확히 (직급·띄어쓰기는 무관, 이름만 정확하면 됨):

담당자프로젝트명 예시
성기민홍길동 식당-성기민 선임
김성주OO고깃집-김성주 책임
대표OO한식집-대표님
⚠️ 위 3명 외 담당자나, 담당자 없는 영업 건은 자동으로 "본사·공통"에 들어갑니다.

③ 본사·공통 (담당자 없는 것)

매입(상품 사오는 돈), 본사 운영비, 인건비, 임대료, 공통 관리비 등.

  • 프로젝트명: 본사(사무실) 또는 비워두면 자동으로 본사·공통 처리
  • ⚠️ 매입·공통비는 담당자에 넣지 마세요 (담당자 순익이 왜곡됩니다)

④ 태양광 (전력판매)

한국전력 전기요금 입금, 종보전기 등은 거래처명에 "한국전력/종보전기"가 있으면 자동 분류됩니다. 별도 프로젝트명 안 적어도 됩니다.

2. 적요(메모) 키워드 — 특수 항목

특정 출금은 비용이 아니라 자산이라 적요에 키워드를 꼭 적어야 합니다.

상황적요에 넣을 키워드처리
설비 투자 (태양광·한전 설비)투자비용 아님 → 투자자산
정부지원사업 자부담금 (수출바우처 등)정부지원비용 아님 → 정부지원 자산(선금성)
예) 수출바우처 자부담 30% 출금 → 적요: 정부지원 수출바우처 자부담
예) 태양광 패널 추가 설치 → 적요: 투자 태양광 설비

3. 계정과목(상대계정) — 평소대로

원래 하던 대로 정확히 입력하면 대시보드가 자동 분류합니다. (매입=외상매입금/상품, 인건비=급여/잡급, 4대보험=예수금/세금과공과, 카드대금=법인카드/미지급비용, 판관비=수수료/운반비 등) 바꿀 필요 없습니다.

❌ 자주 하는 실수 (이것만 피하면 됨)

  1. 프로젝트명 비워두기 → 전부 본사·공통으로 가서 직원별 실적이 안 잡힘
  2. 담당자 이름 오타 (성기만·김성준 ❌ → 성기민·김성주 ✅)
  3. 매입·공통비를 담당자 프로젝트에 넣기 → 담당자 순익이 마이너스로 왜곡
  4. 투자·정부지원 출금에 키워드 안 적기 → 비용으로 잡혀 순이익이 낮게 나옴
  5. 쇼핑몰 건에 "쇼핑몰" 글자 누락 → 영업으로 잘못 분류

📅 월말 마감 체크리스트

  • □ "본사·공통"의 매출이 비정상적으로 크지 않은가? → 크면 담당자 프로젝트명 누락 의심
  • □ 각 직원(성기민/김성주/대표) 매출이 실제 영업 실적과 맞는가?
  • □ 투자·정부지원 출금이 자산에 잘 잡혔는가? (적요 키워드 확인)
  • □ 묶인 선금·미수금 변동 있으면 → 대시보드에서 직접 수정 (사장님)
